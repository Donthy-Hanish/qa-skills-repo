Setting up Appium from Scratch for a React Native App
=====================================================

### Prerequisites

*   Mac with Android Studio installed
*   React Native app (already set up and running)
*   Python installed (preferably the latest version)
*   pip (Python package installer) installed

### Installing Appium

1.  Install the Appium server using the following command:
    ```bash
brew install appium
```
    This will install the Appium server and its dependencies.

2.  Install the Appium Python client using pip:
    ```bash
pip install appium-python-client
```
    This will install the Appium Python client, which allows you to interact with the Appium server.

### Setting up the Android Emulator

1.  Open Android Studio and navigate to **Tools** > **Android** > **AVD Manager**.
2.  Create a new Virtual Device or use an existing one.
3.  Make sure the Virtual Device is running and the API level is compatible with your React Native app.

### Setting up the conftest.py

Create a new file called `conftest.py` and add the following code:
```python
# conftest.py
import pytest
from appium import webdriver

# Appium server settings
appium_server = 'http://localhost:4723/wd/hub'

# Android emulator settings
android_emulator = {
    'platformName': 'Android',
    'platformVersion': '11',  # Replace with your emulator's API level
    'deviceName': 'emulator-5554',  # Replace with your emulator's device name
    'appPackage': 'com.yourcompany.yourapp',  # Replace with your app's package name
    'appActivity': 'com.yourcompany.yourapp.MainActivity',  # Replace with your app's activity name
    'automationName': 'UiAutomator2',
    'noReset': True,
    'fullReset': False
}

# React Native app settings
react_native_app = {
    'app': '/path/to/your/app.apk',  # Replace with the path to your app's APK file
    'unicodeKeyboard': True,
    'resetKeyboard': True
}

# Combine the settings into a single dictionary
desired_capabilities = {**android_emulator, **react_native_app}

# Create a new Appium driver
@pytest.fixture(scope='class')
def driver():
    return webdriver.Remote(appium_server, desired_capabilities)

# Create a new Appium driver for each test
@pytest.fixture
def driver_instance(driver):
    yield driver
```
Replace the following placeholders:

*   `com.yourcompany.yourapp` with your app's package name
*   `com.yourcompany.yourapp.MainActivity` with your app's activity name
*   `/path/to/your/app.apk` with the path to your app's APK file
*   `11` with your emulator's API level
*   `emulator-5554` with your emulator's device name

### Starting the Appium Server

1.  Open a new terminal window and navigate to the directory where you installed Appium.
2.  Start the Appium server using the following command:
    ```bash
appium
```
    This will start the Appium server and make it available at `http://localhost:4723/wd/hub`.

### Running Your Tests

1.  Create a new test file (e.g., `test_app.py`) and add the following code:
    ```python
# test_app.py
import pytest

class TestApp:
    def test_app(self, driver_instance):
        # Your test code here
        pass
```
2.  Run your tests using the following command:
    ```bash
pytest test_app.py
```
    This will start the test and run it on the Android emulator using the Appium driver.

By following these steps, you should be able to set up Appium from scratch for your React Native app and run your tests using the Appium driver.
